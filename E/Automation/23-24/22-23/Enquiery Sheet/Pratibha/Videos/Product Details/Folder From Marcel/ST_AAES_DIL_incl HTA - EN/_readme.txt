ASSA ABLOY Entrance Systems - Distribution & Logistics Sales Tool Presentation

-- System requirements --
Microsoft Windows version 7 or 8
Microsoft Powerpoint/Office version 2010 or 2013

-- Installation instructions --
In order to ensure that the animations in this presentation will be playable it is important that all files in the package are stored at the following location on your computer:
C:\ST_AAES_DIL\
* First: Create this folder on your hard drive
* Second: Unzip all files in the package to this folder
* Third: Run the presentation (ST_AAES_DIL.pptx). 
If a security message appears when you open the powerpoint, make sure you allow external content for the presentation or else the animations won't play.

NOTE! Do not re-organize any of the files in the package into sub-folders or different locations on your hard drive. If you do so, you’ll risk that the animations won’t work  the next time the presentation is launched.
 

NOTE! All files must be in the same directory as the .pptx-file!
